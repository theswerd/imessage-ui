# Palette

Emits the measured light and dark palette as CSS variables for one platform.

## Requirements

React 19, Tailwind CSS 4, and an initialized shadcn project. Uses the standard cn utility at @/lib/utils. Enable dark mode with a .dark ancestor. Standalone primitives need PaletteStyle inside a data-im-platform wrapper; full conversation and app shells include it. Setup: http://localhost:3100/onboard.md

## Install

```sh
npx shadcn@latest add http://localhost:3100/r/palette.json
```

## Usage

```tsx
import { PaletteStyle } from "@/components/message-ui/palette";

<div data-im-platform="ios">
  <PaletteStyle platform="ios" />
  {/* Your Messages components */}
</div>
```

Components render UI only. Supply your own message data, persistence, uploads, and send handlers. Connect your own messaging service.
