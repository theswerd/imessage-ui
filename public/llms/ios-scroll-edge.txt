# iOS scroll edge

The wash iOS 26 lays over a message scrolling up under the conversation's floating nav bar, measured per theme.

## Requirements

React 19, Tailwind CSS 4, and an initialized shadcn project. Uses the standard cn utility at @/lib/utils. Enable dark mode with a .dark ancestor.

## Install

```sh
npx shadcn@latest add http://localhost:3100/r/ios-scroll-edge.json
```

## Usage

```tsx
Install the full collection, then import the components you need from @/components/imessage/.
```

Components render UI only. Supply your own message data, persistence, uploads, and send handlers. No iMessage or Apple service connection is included.
